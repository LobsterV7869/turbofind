🚗 TurboFind
Modern car listings search application with clean UI and advanced filtering for Turbo.az data.

✨ Features
🔍 Search cars by brand, model, or keyword

🎯 Filter by year, price, mileage, fuel type, transmission, and city

🏷️ Brand dropdown for quick filtering

📱 Fully responsive design

🎨 Beautiful UI with gradients, glass effects, and animations

📝 View full car details with descriptions

🔗 Direct link to original Turbo.az listings
